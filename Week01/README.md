# Week 1 — Java OOP + complexity

**Roadmap source:** [Hilti Technical Learning Roadmap — 19 Weeks](https://app.notion.com/p/3fd2548df0078107b67ed8a3389cc999).

**Classification:** This folder contains migrated Week 1 source material plus redesigned supplementary practice. The new tutorial flow is self-study, not official WIX1002 assessment work. Use the source map below for provenance.

## Learning objectives from the roadmap

**Java:** classes, objects, constructors, encapsulation, inheritance, polymorphism, interfaces, abstract classes, exceptions and debugging; reference semantics and the purpose of `equals()` / `hashCode()`.

**DSA:** Big-O and time/space complexity; arrays and strings.

**Mastery checkpoint:** build a small multi-class Java program; explain interface versus abstract class; analyse common loops and array/string operations.


## How to work through the lessons

Attempt each milestone in a scratch file, then check the stated cases or trace against your actual output. Keep the first attempt and the bug you found. If you use AI for feedback, ask for a hint about your next step or a review of your reasoning rather than a complete solution.

1. [Tutorial 01 — Student records, objects, and constructors](Tutorials/Tutorial01/README.md)
