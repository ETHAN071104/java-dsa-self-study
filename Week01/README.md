# Week 1 — Java OOP + complexity

## Learning objectives

**Java:** classes, objects, constructors, encapsulation, inheritance, polymorphism, interfaces, abstract classes, exceptions and debugging. Understand reference semantics and the purpose of equals() / hashCode().

**DSA:** Big-O and time/space complexity; arrays and strings.

**Mastery checkpoint:** Build a small multi-class Java program; explain interface vs abstract class; analyse common loops and array/string operations.

The source page's final checkpoint sentence ends at “build a small multi-class Java”; the complete checkpoint above is transcribed from the linked 19-week roadmap's Week 1 entry, which matches this page's objectives.
