## LeetCode 1 — Two Sum (Easy)

Given an integer array nums and an integer target, return the indices of two numbers that add up to target. Assume exactly one valid solution exists.

Tasks:

- Implement a brute-force solution.
- Develop a more efficient solution using a HashMap.
- Compare time and auxiliary space complexity.

Acceptance criteria: Both solutions pass the relevant tests, and you can explain the trade-offs.

## LeetCode 217 — Contains Duplicate (Easy)

Given an integer array nums, return true if any value appears at least twice, and return false if every element is distinct.

Tasks:

- Implement a nested-loop solution.
- Implement a HashSet solution.
- Compare their complexity.

Acceptance criteria: Explain why the hash-based solution typically runs in expected O(n) time.

[Solve on LeetCode](https://leetcode.com/problems/contains-duplicate/?utm_source=chatgpt.com)

## LeetCode 242 — Valid Anagram (Easy)

Given two strings s and t, return true if t is an anagram of s, and false otherwise.

Tasks:

- Implement a character-frequency solution.
- Handle strings of different lengths.
- Analyze the time and space complexity.

[Solve on LeetCode](https://leetcode.com/problems/valid-anagram/?utm_source=chatgpt.com)

Tasks:

- Attempt a brute-force solution.
- Optimize to a single pass.
- Track the minimum price seen so far and the maximum profit.
