# Week 3 — Linear Data Structures (1–7 November)

**Roadmap source:** [Hilti Technical Learning Roadmap — 19 Weeks](https://app.notion.com/p/3fd2548df0078107b67ed8a3389cc999).

**Classification:** supplementary Java/DSA practice based on the 19-week roadmap. The individual Week 3 Notion page contains only an empty block, so these lessons are newly authored and are not official WIX1002 work.

## Roadmap objectives

Stacks, queues, deque, linked-list nodes and traversal, reversing a linked list, fast/slow pointers, stack-based matching, and understanding queue use in BFS.

**Mastery checkpoint:** explain the trade-offs among arrays, linked lists, stacks, and queues; implement or use them correctly and test edge cases.


## How to work through the lessons

Attempt each milestone in a scratch file, then check the stated cases or trace against your actual output. Keep the first attempt and the bug you found. If you use AI for feedback, ask for a hint about your next step or a review of your reasoning rather than a complete solution.
