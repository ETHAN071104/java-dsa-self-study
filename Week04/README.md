# Week 4 — Search, Sort + Java Stability Gate (8–14 November)

**Roadmap source:** [Hilti Technical Learning Roadmap — 19 Weeks](https://app.notion.com/p/3fd2548df0078107b67ed8a3389cc999).

**Classification:** supplementary Java/DSA practice based on the 19-week roadmap. The individual Week 4 Notion page is empty, so these lessons are newly authored; they are not official WIX1002 work.

## Roadmap objectives

**Java:** lambdas, `Comparator`, basic Stream API, JUnit fundamentals, and debugging.

**DSA:** binary search, sorting complexity, recursion basics, and introductory tree traversal.

**Mastery checkpoint:** implement binary search including empty, duplicate, and boundary cases; write basic tests. If Java, Collections, and Big-O are not independently usable yet, consolidate this phase before increasing AI workload.


## How to work through the lessons

Attempt each milestone in a scratch file, then check the stated cases or trace against your actual output. Keep the first attempt and the bug you found. If you use AI for feedback, ask for a hint about your next step or a review of your reasoning rather than a complete solution.

## Recommended order

1. [Tutorial 01 — Build a sorted score report](Tutorials/Tutorial01/README.md): comparator, lambda, stream, and sort/filter costs.
2. [Tutorial 02 — Implement binary search](Tutorials/Tutorial02/README.md): interval invariant and boundary behavior.
3. [Tutorial 03 — Traverse a tree recursively](Tutorials/Tutorial03/README.md): recursion, call stack, tree traversal, and sort comparison.
4. [Tutorial 04 — Test and debug a search method](Tutorials/Tutorial04/README.md): contracts, regression tests, JUnit basics, and debugging.
5. Complete [Lab 01](Labs/Lab01/README.md) and [Lab 02](Labs/Lab02/README.md), then use the [Optional Checkpoint](OptionalCheckpoint/README.md).

Work through implementation steps before the short Chinese concept notes and English explanation prompts. Use the JUnit starter only when JUnit 5 is already configured; manual test specifications are acceptable.
